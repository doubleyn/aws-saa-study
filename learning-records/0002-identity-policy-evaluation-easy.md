# 자격 증명 기반 정책의 판정 3규칙은 이미 쉽게 다룬다

레슨 0001(암묵적 거부 / 일치하는 Allow / 명시적 Deny 우선, Action·Resource 와일드카드)을 사용자가 "쉬웠다"고 평가했다(2026-11-16). 점수는 보고하지 않았다.

**Evidence**: 자기 평가만 있다. 레슨 0002 퀴즈에 0001 규칙(명시적 Deny)을 섞어 넣어 실제로 기억하는지 간접 확인한다.

**Implications**: 같은 개념을 다시 설명하지 말고 속도를 올린다. 레슨 0002부터는 한 레슨에 규칙을 더 많이 담고, 단순 판정 문제보다 시험 형식의 시나리오 문제 비중을 늘린다.
