VPC 네트워킹 치트시트

서브넷, 라우팅, 방화벽, NAT, 엔드포인트, VPC 간·하이브리드 연결을 한 장에. 레슨 0004~0007.

VPC · 서브넷 · 라우팅 (0004)

  • VPC·서브넷 IPv4 CIDR: /16~/28. RFC 1918 대역 권장. 기존 CIDR 크기 변경 불가 → 보조 CIDR 추가.
  • 서브넷은 AZ 하나에만. 고가용성 = 2개 이상 AZ에 서브넷.
  • 서브넷마다 5개 주소 예약 (네트워크, +1 라우터, +2 DNS, +3 예약, 브로드캐스트). /24 → 251개.
  • 라우팅: 가장 긴 접두사 일치. 모든 테이블에 local 라우트. 명시적으로 연결 안 된 서브넷은 기본 라우팅 테이블을 따름.
서브넷정의 (라우팅 테이블이 결정)
퍼블릭IGW로 가는 직접 라우트 있음
프라이빗IGW 라우트 없음 (나가려면 NAT)
VPN 전용VGW를 통한 VPN 라우트, IGW 라우트 없음
격리VPC 밖 라우트 없음

인터넷 통신 3조건: IGW 연결 + 0.0.0.0/0 → IGW 라우트 + 퍼블릭 IPv4/탄력적 IP. (그리고 SG·NACL 허용.) IGW는 무료·고가용, 대역폭 제약 없음.

보안 그룹 vs NACL (0005)

보안 그룹NACL
수준인스턴스서브넷
규칙허용만허용 + 거부
평가모든 규칙번호 오름차순, 첫 일치로 끝
응답자동 허용 (상태 저장)명시 허용 필요 (상태 비저장)
기본값새 SG: 인바운드 없음, 아웃바운드 전체 허용기본 NACL: 전체 허용. 모든 NACL에 * 거부 규칙
  • 특정 IP 차단 → NACL 거부 규칙(허용보다 낮은 번호).
  • SG 참조: 소스에 다른 SG ID → 그 SG 인스턴스의 사설 IP 허용 (ALB SG → 웹 SG → DB SG).
  • 임시 포트: Linux 32768–61000, Windows 2008+ 49152–65535, ELB·NAT GW·Lambda 1024–65535. 실무는 1024–65535. 서버면 NACL 아웃바운드, 클라이언트면 NACL 인바운드.
