EC2 인스턴스 이름 (c7gn.xlarge)

시리즈 c · 세대 7 · 옵션 gn · 크기 xlarge. 시리즈: M/T 범용(T=버스트, CPU 크레딧), C 컴퓨팅, R/X 메모리, I/D 스토리지, P/G/Inf/Trn 가속, Hpc. 옵션: g Graviton, a AMD, i Intel, d 인스턴스 스토어, n 네트워크, e 추가 메모리·스토리지, z 고주파수.

Auto Scaling

단서방식
지표를 목표값으로 유지, 경보 자동 관리 (기본·권장)대상 추적
경보 초과 크기별 다른 조정량단계
조정량 하나 + 휴지 기간(기본 300초, 단순에만 적용) — 비권장단순
시각을 정확히 앎(cron)예약
반복 패턴 + 긴 초기화, 미리 확장(축소 안 함), 24시간 데이터 필요, 예측 전용 모드로 시작예측
  • 지표: 인스턴스 수에 반비례하는 것(평균 CPU, ALBRequestCountPerTarget, 인스턴스당 SQS 백로그). 부적합: LB 전체 RequestCount, Latency, 큐 메시지 수 그 자체. 세부 모니터링(1분) 권장.
  • 정책이 겹치면 가장 큰 용량 채택. 대상 추적·단계는 휴지 기간 대신 워밍업.
  • 기본 상태 확인 = EC2 상태 확인. ELB 상태 확인은 켜야 교체에 반영.
  • 수명 주기 후크: Pending:Wait/Terminating:Wait, 기본 1시간, complete-lifecycle-action.
  • 시작 템플릿(버전 관리, 혼합 인스턴스·Spot) 권장. 다중 AZ 균등 분배, 재조정 시 먼저 띄우고 나중에 종료.
  • 수직 조정은 EBS 인스턴스 중지 필요(다운타임). 수평 확장 = Well-Architected 신뢰성 원칙.

Lambda · 컨테이너

Lambda제한 시간 기본 3초·최대 900초. 메모리 128~10,240 MB, CPU는 메모리 비례(1,769 MB ≈ 1 vCPU). 계정 동시성 리전당 기본 1,000. 동기 6 MB/비동기 1 MB. 이미지 10 GB
예약 동시성몫 확보 + 상한, 무료 → 다른 함수 때문에 스로틀링, 다운스트림 보호
프로비저닝된 동시성미리 초기화, 유료 → 콜드 스타트
ECSAWS 네이티브, 낮은 운영 부담. 작업 정의 → 작업 → 서비스
