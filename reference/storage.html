S3 데이터 관리 · 보호

수명 주기전환(아래로만, 폭포) + 만료. 기존 객체에도 적용. Flexible→Deep Archive만, Deep Archive에서는 이동 불가. 128KB 미만 기본 미전환. 최소 보관 전 이동·삭제 시 잔여 기간 과금. AbortIncompleteMultipartUpload로 미완료 업로드 정리
버전 관리한 번 켜면 비버전 복귀 불가(일시 중지만). 단순 DELETE → 삭제 마커. 버전마다 전체 과금. MFA Delete: 루트(버킷 소유자)만, CLI/API로
복제CRR(다른 리전: 규정·지연) / SRR(같은 리전: 로그 집계, 계정 간, 데이터 주권). 양쪽 버전 관리 + IAM 역할. 교차 계정은 대상 버킷 정책 필요. 새 객체만 → 기존은 Batch Replication. RTC: 15분 내 99.99% SLA. 버전 지정 삭제는 미복제
Object LockWORM, 버전 관리 필수. 거버넌스 = s3:BypassGovernanceRetention로 해제 가능. 규정 준수 = 루트 포함 아무도 불가. 법적 보존 = 기간 없음, 제거 전까지
공유 · 비용미리 서명된 URL: 생성자 권한, IAM 사용자 SigV4 최대 7일, 임시 자격 증명이면 그 만료와 함께. Requester Pays: 요청·다운로드는 요청자, 저장은 소유자, 익명 불가
성능접두사당 초당 3,500 쓰기 / 5,500 읽기, 접두사 수 무제한. 100MB 이상 멀티파트. Transfer Acceleration: 엣지 경유 원거리 업로드, 버킷 이름에 마침표 불가

  • Multi-Attach: io1·io2만, 같은 AZ의 Nitro 인스턴스 최대 16대, 클러스터 파일 시스템 필요, 부팅 불가.
  • 스냅숏: 증분, 리전의 모든 AZ에 복제 → 다른 AZ로 옮기려면 스냅숏 후 복원. 자동 백업 아님(DLM·AWS Backup). Fast Snapshot Restore = 즉시 최대 성능.
  • 인스턴스 스토어: 호스트 물리 디스크, 추가 요금 없음. 재부팅 유지 / 중지·최대 절전·종료 시 소멸. 분리·재연결 불가. 캐시·스크래치용.
