데이터 전송 요금의 방향 (0026)

경로과금
인터넷 → AWS무료
AWS → 인터넷과금
AZ 간 (같은 리전)과금, 양방향 계량 (일부 서비스 예외)
리전 간소스 리전 아웃바운드에 과금, 수신 리전 인바운드 무료
AWS 오리진 → CloudFront무료 (CloudFront → 뷰어만 과금)

NAT 게이트웨이

  • 과금 = 시간당 + 처리 GB당. AZ 하나에 생성, 그 AZ 안에서만 중복.
  • 절감 ①: 리소스를 NAT와 같은 AZ에 두거나 AZ마다 NAT + 같은 AZ 라우팅 (AZ 간 전송 회피, AZ 독립 구조).
  • 절감 ②: AWS 서비스 트래픽은 VPC 엔드포인트로. S3·DynamoDB 게이트웨이 엔드포인트는 추가 요금 없음. 인터페이스 엔드포인트는 PrivateLink 요금 비교.
  • 공유 NAT 1개: 싸지만 그 AZ 장애 시 다른 AZ도 인터넷 상실 → 개발·테스트용.
  • NAT 인스턴스: 인스턴스 유형·시간 과금, 장애 조치·패치 직접. AWS 권장은 NAT 게이트웨이.
